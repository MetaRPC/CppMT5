# MT5Service — Symbol Methods (Mid-Level)

> 16 methods for symbols, quotes, parameters, sessions, tick value, and bars — all returning friendly C++ structs with UTC times. Wrappers over [MT5Account Symbol Information](../MT5Account/2.%20Symbol_Information/Symbol_Information.Overview.md) and [Additional Methods](../MT5Account/6.%20Additional_Methods/Additional_Methods.Overview.md).

**🧩 API Layer:** **MID-LEVEL**. **Implementation:** `src/mt5_service.cpp`.

---

## 📋 The methods

| Method | Returns | Description |
|--------|---------|-------------|
| `symbolsTotal(selectedOnly=false)` | `int` | Count of symbols (all or Market Watch) |
| `symbolExist(symbol)` | `bool` | Does the broker know the symbol |
| `symbolName(index, selectedOnly=false)` | `std::string` | Name by index |
| `symbolSelect(symbol, select=true)` | `bool` | Add/remove in Market Watch |
| `symbolIsSynchronized(symbol)` | `bool` | Is its data synchronized |
| `symbolList()` | `std::vector<std::string>` | All symbol names |
| `symbolInfoTick(symbol)` | `Tick` | Latest tick (UTC) |
| `symbolParams(symbol)` | `SymbolInfo` | **Recommended** — full spec, one symbol |
| `symbolParamsMany(nameFilter="")` | `std::vector<SymbolInfo>` | Full spec, many symbols |
| `symbolInfoDouble(symbol, propertyId)` | `double` | One double property |
| `symbolInfoInteger(symbol, propertyId)` | `int64_t` | One integer property |
| `symbolInfoString(symbol, propertyId)` | `std::string` | One string property |
| `symbolInfoMarginRate(symbol, orderType)` | `MarginRate` | Initial/maintenance margin rates |
| `symbolInfoSessionQuote(symbol, day, idx=0)` | `SessionTime` | Quote session window |
| `symbolInfoSessionTrade(symbol, day, idx=0)` | `SessionTime` | Trade session window |
| `tickValueWithSize(symbols)` | `std::vector<TickValueSize>` | Tick value/size for P&L |
| `priceHistory(symbol, tf, from, to, maxBars=0)` | `std::vector<Bar>` | OHLC bars in a window |
| `lastBars(symbol, tf, count)` | `std::vector<Bar>` | Newest `count` bars |

> `day` is `0=Sunday … 6=Saturday`. `orderType` / property `propertyId` are plain `int` (pass the protobuf enum value). `tf` is the `Timeframe` enum.

## 📦 DTOs

```cpp
struct Tick {                      // symbolInfoTick()
    std::string symbol; int64_t time, timeMsc;   // UTC seconds / ms
    double bid, ask, last, volume; uint32_t flags;
    bool twoSided() const;         // bid>0 && ask>0 && ask>bid
};

struct SymbolInfo {                // symbolParams() / symbolParamsMany()
    std::string name, description, path;
    std::string currencyBase, currencyProfit, currencyMargin;
    int digits; double point, bid, ask; int spread;
    double contractSize, tickSize, tickValue;
    double volumeMin, volumeMax, volumeStep, volumeLimit;
    int stopsLevel, freezeLevel, tradeMode, tradeCalcMode, tradeExeMode, swapMode;
    double swapLong, swapShort; std::vector<int> fillingModes;
    bool visible, selected, exist; int64_t time;
};

struct Bar { int64_t time; double open, high, low, close;   // time = UTC seconds
             int64_t tickVolume, realVolume; int spread; };

struct MarginRate   { double initial, maintenance; };
struct SessionTime  { int64_t from, to; };                   // UTC seconds
struct TickValueSize{ std::string symbol; double tickValue, tickValueProfit,
                      tickValueLoss, tickSize, contractSize; };
```

`Timeframe` enum: `M1,M2,M3,M4,M5,M6,M10,M12,M15,M20,M30, H1,H2,H3,H4,H6,H8,H12, D1,W1,MN1` (raw MQL5 `ENUM_TIMEFRAMES` values).

## 💡 Examples

### Current price

```cpp
Tick t = service.symbolInfoTick("EURUSD");
std::printf("%.5f / %.5f (spread %.5f)\n", t.bid, t.ask, t.ask - t.bid);
```

### Full spec in one call (prefer over many single reads)

```cpp
SymbolInfo s = service.symbolParams("EURUSD");
std::printf("%s: digits=%d point=%.5f volMin=%.2f step=%.2f tickValue=%.5f\n",
            s.name.c_str(), s.digits, s.point, s.volumeMin, s.volumeStep, s.tickValue);
```

### Make a symbol quotable, then quote it

```cpp
if (service.symbolSelect("USDMXN") && service.symbolIsSynchronized("USDMXN")) {
    Tick t = service.symbolInfoTick("USDMXN");
    std::printf("USDMXN %.5f/%.5f\n", t.bid, t.ask);
}
```

### Last 100 H1 bars

```cpp
std::vector<Bar> bars = service.lastBars("EURUSD", Timeframe::H1, 100);
std::printf("%zu bars, last close %.5f\n", bars.size(), bars.empty() ? 0 : bars.back().close);
```

### Tick value for position sizing

```cpp
for (const TickValueSize& v : service.tickValueWithSize({"EURUSD","XAUUSD"}))
    std::printf("%s tickValue=%.5f tickSize=%.5f\n",
                v.symbol.c_str(), v.tickValue, v.tickSize);
```

### Trade session on Monday

```cpp
SessionTime st = service.symbolInfoSessionTrade("EURUSD", /*Monday*/1, 0);
std::printf("Trade session: %lld .. %lld (UTC)\n", (long long)st.from, (long long)st.to);
```

## 🔧 When to use which

1. **Need everything about a symbol** → `symbolParams()` (one call vs 10+).
2. **One field only** → `symbolInfoDouble/Integer/String`.
3. **Whole watchlist** → `symbolParamsMany()`.
4. **Just the price** → `symbolInfoTick()`.
5. **Candles** → `lastBars()` / `priceHistory()`.
