# MT5Service — Market Depth Methods (Mid-Level)

> 3 methods for the Depth-of-Market / order book, returning a `std::vector<BookEntry>` instead of protobuf. Wrappers over [MT5Account Market Depth (DOM)](../MT5Account/5.%20Market_Depth(DOM)/Market_Depth.Overview.md).

**🧩 API Layer:** **MID-LEVEL**. **Implementation:** `src/mt5_service.cpp`.

---

## 📋 The methods

| Method | Returns | Description |
|--------|---------|-------------|
| `marketBookAdd(symbol)` | `bool` | Subscribe to a symbol's DOM |
| `marketBookGet(symbol)` | `std::vector<BookEntry>` | Current DOM snapshot |
| `marketBookRelease(symbol)` | `bool` | Unsubscribe |

> DOM is a **subscription**: `marketBookAdd` → poll `marketBookGet` → `marketBookRelease`. Skipping the add returns an empty book; skipping the release leaks the subscription.

---

## 📦 DTO

```cpp
struct BookEntry {                 // one DOM level
    int type;                      // 0 SELL, 1 BUY, 2 SELL_MARKET, 3 BUY_MARKET
    double price;
    int64_t volume;
    double volumeReal;
};
```

---

## 💡 Examples

### Full lifecycle

```cpp
if (service.marketBookAdd("EURUSD")) {
    for (const BookEntry& lvl : service.marketBookGet("EURUSD")) {
        const char* side = (lvl.type == 1 || lvl.type == 3) ? "BID" : "ASK";
        std::printf("%s  %.5f  x%lld\n", side, lvl.price, (long long)lvl.volume);
    }
    service.marketBookRelease("EURUSD");
}
```

### Best bid / best ask from the book

```cpp
double bestBid = 0, bestAsk = 1e18;
for (const BookEntry& l : service.marketBookGet("EURUSD")) {
    if (l.type == 1 /*BUY*/)  bestBid = std::max(bestBid, l.price);
    if (l.type == 0 /*SELL*/) bestAsk = std::min(bestAsk, l.price);
}
std::printf("top of book: %.5f / %.5f\n", bestBid, bestAsk);
```

### RAII cleanup

```cpp
struct Dom {
    MT5Service& s; std::string sym; bool ok;
    Dom(MT5Service& svc, std::string symbol) : s(svc), sym(std::move(symbol)),
        ok(s.marketBookAdd(sym)) {}
    ~Dom() { if (ok) s.marketBookRelease(sym); }
};
// { Dom d(service, "EURUSD"); auto book = service.marketBookGet("EURUSD"); }  // auto-released
```

---

## 🔧 Notes

* **Not all symbols/brokers provide DOM** — `marketBookAdd` returns `false` when unavailable.
* **Poll, don't spin** — `marketBookGet` is a snapshot.
* **Always release** — prefer an RAII guard.
