# MT5Service — Trading Methods (Mid-Level)

> 6 methods to place, modify, close, validate and calculate trades — with plain arguments and friendly results. Wrappers over [MT5Account Trading Operations](../MT5Account/4.%20Trading_Operations/Trading_Operations.Overview.md).

**🧩 API Layer:** **MID-LEVEL**. **Implementation:** `src/mt5_service.cpp`.

---

## 📋 The methods

| Method | Returns | Description |
|--------|---------|-------------|
| `orderSend(OrderRequest)` | `OrderResult` | Place a market or pending order |
| `orderModify(ticket, sl, tp, price=0, stopLimit=0)` | `OrderResult` | Modify SL/TP (and pending price) |
| `orderClose(ticket, volume=0, slippage=10)` | `OrderResult` | Close/partial-close or delete pending |
| `orderCheck(OrderRequest)` | `OrderCheckResult` | Dry-run validation before sending |
| `orderCalcMargin(symbol, orderType, volume, price)` | `double` | Margin required |
| `orderCalcProfit(symbol, orderType, volume, open, close)` | `double` | Potential profit |

> `orderType` is a plain `int` (pass the protobuf order-type enum value). `volume == 0` on `orderClose` closes the whole position.

## 📦 DTOs & enum

```cpp
enum class TradeAction {           // OrderRequest::action
    Buy=0, Sell=1, BuyLimit=2, SellLimit=3,
    BuyStop=4, SellStop=5, BuyStopLimit=6, SellStopLimit=7
};

struct OrderRequest {              // input to orderSend()/orderCheck()
    std::string symbol; TradeAction action; double volume;
    double price;                  // 0 = market (Buy/Sell); required for pendings
    double stopLoss, takeProfit, stopLimit;
    int slippage;                  // points (default 10)
    int64_t magic;                 // sent as expert_id
    std::string comment; int64_t expiration;   // unix seconds; 0 = GTC
};

struct OrderResult {               // orderSend/Modify/Close
    uint32_t retcode;              // 10009 DONE, 10008 PLACED, 10010 DONE_PARTIAL
    int64_t ticket, deal, order; double volume, price, bid, ask;
    std::string comment, retcodeName, retcodeDescription; uint32_t requestId;
    bool ok() const;               // true for accepted retcodes
};

struct OrderCheckResult {          // orderCheck
    uint32_t retcode;              // 0 / 10009 = would succeed
    double balance, equity, profit, margin, freeMargin, marginLevel;
    std::string comment; bool ok() const;
};
```

---

## 📖 Methods

### `orderSend(const OrderRequest&) → OrderResult`

Fill only the fields relevant to the action. Market BUY/SELL may leave `price = 0`; pendings need `price` (and `stopLimit` for `*StopLimit`).

### `orderModify(ticket, stopLoss, takeProfit, price=0, stopLimit=0) → OrderResult`

For a **position**, set `stopLoss`/`takeProfit` (leave `price` 0). For a **pending order**, you can also move `price`/`stopLimit`.

### `orderClose(ticket, volume=0, slippage=10) → OrderResult`

`volume = 0` → close the whole position; a smaller value → partial close. Also deletes a pending order by ticket.

### `orderCheck(const OrderRequest&) → OrderCheckResult`

Dry-run: reports margin, free margin and a retcode **without executing**. `ok()` = would succeed.

### `orderCalcMargin(symbol, orderType, volume, price) → double`

Margin the trade would require (account currency).

### `orderCalcProfit(symbol, orderType, volume, openPrice, closePrice) → double`

Profit a move would yield (account currency).

## 💡 Examples

### Market BUY with SL/TP

```cpp
OrderRequest req;
req.symbol = "EURUSD";
req.action = TradeAction::Buy;
req.volume = 0.01;
req.price  = service.symbolInfoTick("EURUSD").ask;
req.stopLoss   = req.price - 0.0050;
req.takeProfit = req.price + 0.0050;
req.magic = 777; req.comment = "demo-buy";

OrderResult r = service.orderSend(req);
if (r.ok()) std::printf("DONE: order #%lld @ %.5f\n", (long long)r.order, r.price);
else        std::printf("rejected: %u %s\n", r.retcode, r.retcodeDescription.c_str());
```

### Validate first

```cpp
OrderCheckResult chk = service.orderCheck(req);
if (!chk.ok()) { std::printf("invalid: %s\n", chk.comment.c_str()); return; }
std::printf("margin %.2f, free after %.2f\n", chk.margin, chk.freeMargin);
```

### Pending BUY LIMIT

```cpp
OrderRequest p;
p.symbol = "EURUSD"; p.action = TradeAction::BuyLimit;
p.volume = 0.01; p.price = 1.0800; p.takeProfit = 1.0900;
std::printf("retcode %u\n", service.orderSend(p).retcode);
```

### Move stop to break-even

```cpp
for (const Position& pos : service.openedOrders().positions) {
    if (pos.symbol != "EURUSD") continue;
    OrderResult r = service.orderModify(pos.ticket, pos.priceOpen, pos.takeProfit);
    std::printf("modify retcode %u\n", r.retcode);
    break;
}
```

### Close / scale out

```cpp
service.orderClose(ticket);                 // whole position
service.orderClose(ticket, pos.volume/2);   // half
```

### Pre-trade math

```cpp
namespace pb = mt5_term_api;
double margin = service.orderCalcMargin("EURUSD", pb::ORDER_TYPE_TF_BUY, 1.0, 1.0850);
double profit = service.orderCalcProfit("EURUSD", pb::ORDER_TYPE_TF_BUY, 1.0, 1.0850, 1.0900);
std::printf("margin %.2f, profit at +50pips %.2f\n", margin, profit);
```

## 🔧 Rules

1. **Check the result.** `OrderResult::ok()` (or `retcode == 10009`); `OrderCheckResult::ok()`.
2. **Normalize volume** to `SymbolInfo::volumeStep` and **respect `stopsLevel`** for SL/TP.
3. **Validate risky sends** with `orderCheck()` first.
4. **Trade timeout** via `service.options().tradeTimeoutMs`.
