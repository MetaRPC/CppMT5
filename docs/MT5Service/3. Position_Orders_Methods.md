# MT5Service — Position & Orders Methods (Mid-Level)

> 6 methods for live positions, pending orders, ticket lists and history — all returning friendly C++ structs with UTC times. Wrappers over [MT5Account Positions & Orders](../MT5Account/3.%20Positions_Orders/Positions_Orders.Overview.md).

**🧩 API Layer:** **MID-LEVEL**. **Implementation:** `src/mt5_service.cpp`.

---

## 📋 The methods

| Method | Returns | Description |
|--------|---------|-------------|
| `positionsTotal()` | `int` | Count of open positions |
| `openedOrders()` | `OpenedOrders` | Positions **and** pending orders (friendly) |
| `positions(magic=-1)` | `std::vector<Position>` | Open positions (optionally by magic) |
| `openedOrdersTickets()` | `OpenedTickets` | **Lightweight** — ticket numbers only |
| `orderHistory(from, to)` | `std::vector<HistoryItem>` | Orders/deals history (UTC window) |
| `positionsHistory(from, to)` | `std::vector<PositionHistory>` | Closed positions (UTC window) |

> `from` / `to` are **unix seconds, UTC** (when the service runs with `utcTimes = true`, the default).

---

## 📦 DTOs

```cpp
struct Position {                  // openedOrders().positions, positions()
    int64_t ticket; std::string symbol; int type;   // 0 BUY, 1 SELL
    double volume, priceOpen, priceCurrent, stopLoss, takeProfit;
    double profit, swap, commission; int64_t magic; std::string comment;
    int64_t openTime, identifier; int reason;
    bool isBuy() const;            // type == 0
};

struct PendingOrder {              // openedOrders().orders
    int64_t ticket; std::string symbol; int type, state;
    double volumeInitial, volumeCurrent, priceOpen, priceCurrent;
    double stopLoss, takeProfit, stopLimit; int64_t magic; std::string comment;
    int64_t timeSetup, timeExpiration, positionId;
};

struct OpenedOrders { std::vector<Position> positions; std::vector<PendingOrder> orders; };
struct OpenedTickets { std::vector<int64_t> positionTickets, orderTickets; };

struct HistoryItem {               // orderHistory()
    HistoryOrder order; bool hasOrder; Deal deal; bool hasDeal;
};

struct PositionHistory {           // positionsHistory()
    int64_t ticket; std::string symbol; int orderType;
    double volume, openPrice, closePrice, stopLoss, takeProfit;
    double profit, swap, commission, fee;
    int64_t openTime, closeTime, magic; std::string comment;
};
```

(`HistoryOrder` and `Deal` are declared in `mt5_service.hpp`.)

## 💡 Examples

### Count, then list

```cpp
if (service.positionsTotal() > 0) {
    double total = 0;
    for (const Position& p : service.openedOrders().positions) {
        std::printf("#%lld %s %s %.2f  P/L %.2f\n",
                    (long long)p.ticket, p.symbol.c_str(),
                    p.isBuy() ? "BUY" : "SELL", p.volume, p.profit);
        total += p.profit;
    }
    std::printf("Total floating P/L: %.2f\n", total);
}
```

### Positions for one EA (magic filter)

```cpp
for (const Position& p : service.positions(/*magic*/777))
    std::printf("#%lld %s %.2f\n", (long long)p.ticket, p.symbol.c_str(), p.volume);
```

### Lightweight ticket diff

```cpp
OpenedTickets t = service.openedOrdersTickets();
std::printf("%zu open positions, %zu pending orders\n",
            t.positionTickets.size(), t.orderTickets.size());
```

### Last 30 days of closed positions

```cpp
#include <ctime>
int64_t now = (int64_t)std::time(nullptr);
auto hist = service.positionsHistory(now - 30*24*3600, now);

double net = 0; int wins = 0;
for (const PositionHistory& h : hist) { net += h.profit; if (h.profit > 0) ++wins; }
std::printf("Net %.2f over %zu trades (%d wins)\n", net, hist.size(), wins);
```

### Order/deal history

```cpp
auto items = service.orderHistory(now - 7*24*3600, now);
for (const HistoryItem& it : items) {
    if (it.hasDeal)  std::printf("deal  #%lld %s P/L %.2f\n",
                                 (long long)it.deal.ticket, it.deal.symbol.c_str(), it.deal.profit);
    if (it.hasOrder) std::printf("order #%lld %s\n",
                                 (long long)it.order.ticket, it.order.symbol.c_str());
}
```

## 🔧 When to use which

1. **"Anything open?"** → `positionsTotal()`.
2. **Full live picture** → `openedOrders()`.
3. **Only tickets (cheap polling)** → `openedOrdersTickets()`.
4. **Per-position P&L report** → `positionsHistory()`.
5. **Order/deal audit** → `orderHistory()`.
