# MT5Sugar · Position Information

> Read open positions and their P&L — all, by symbol, by ticket, or aggregated. Wraps [MT5Service positions](../MT5Service/3.%20Position_Orders_Methods.md). Returns the friendly `Position` struct.

**🧩 Layer:** HIGH (MT5Sugar).

```cpp
struct Position { int64_t ticket; std::string symbol; int type; /*0 BUY,1 SELL*/
                  double volume, priceOpen, priceCurrent, stopLoss, takeProfit;
                  double profit, swap, commission; int64_t magic; std::string comment;
                  int64_t openTime, identifier; int reason; bool isBuy() const; };
```

---

## `getOpenPositions()`

All open positions.

**Signature:** `std::vector<Position> getOpenPositions();`

**Examples**

*1 — list them*
```cpp
for (const Position& p : sugar.getOpenPositions())
    std::printf("#%lld %s %s %.2f  P/L %.2f\n",
                (long long)p.ticket, p.symbol.c_str(),
                p.isBuy() ? "BUY" : "SELL", p.volume, p.profit);
```

*2 — close the worst loser*
```cpp
auto ps = sugar.getOpenPositions();
if (!ps.empty()) {
    const Position* worst = &ps[0];
    for (const auto& p : ps) if (p.profit < worst->profit) worst = &p;
    if (worst->profit < 0) sugar.closePosition(worst->ticket);
}
```

---

## `getPositionsBySymbol(symbol)`

Open positions on one symbol.

**Signature:** `std::vector<Position> getPositionsBySymbol(const std::string& symbol);`

**Examples**

*1 — net volume on a symbol*
```cpp
double net = 0;
for (const Position& p : sugar.getPositionsBySymbol("EURUSD"))
    net += p.isBuy() ? p.volume : -p.volume;
std::printf("net EURUSD exposure: %.2f lots\n", net);
```

---

## `getPositionByTicket(ticket, found&)`

One position by ticket; `found` is set `false` if there is none.

**Signature:** `Position getPositionByTicket(int64_t ticket, bool& found);`

**Examples**

*1 — look one up safely*
```cpp
bool found = false;
Position p = sugar.getPositionByTicket(123456, found);
if (found) std::printf("profit %.2f\n", p.profit);
else       std::puts("no such position");
```

---

## `hasOpenPosition(symbol)` / `countOpenPositions()`

Is there any position on the symbol / how many positions in total.

**Signatures:** `bool hasOpenPosition(const std::string& symbol);` · `int countOpenPositions();`

**Examples**

*1 — don't stack entries*
```cpp
if (!sugar.hasOpenPosition("EURUSD"))
    sugar.buyMarket("EURUSD", 0.01);
```

*2 — cap concurrent positions*
```cpp
if (sugar.countOpenPositions() < 5)
    sugar.buyMarket("EURUSD", 0.01);
```

---

## `getTotalProfit()` / `getProfitBySymbol(symbol)`

Summed floating profit across all positions / on one symbol.

**Signatures:** `double getTotalProfit();` · `double getProfitBySymbol(const std::string& symbol);`

**Examples**

*1 — book-wide target*
```cpp
if (sugar.getTotalProfit() > 50) sugar.closeAllPositions();
```

*2 — per-symbol target*
```cpp
if (sugar.getProfitBySymbol("EURUSD") > 20) sugar.closeAllBySymbol("EURUSD");
```
