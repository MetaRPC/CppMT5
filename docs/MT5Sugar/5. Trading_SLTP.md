# MT5Sugar · Trading with SL/TP

> Entries that carry a stop loss and take profit — as **absolute prices** or as **pip distances**. Returns the resulting ticket (`0` on rejection). Wraps [MT5Service::orderSend](../MT5Service/4.%20Trading_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar).

> **Rounding:** the `*WithSLTP` methods send prices **as given**; the `*WithPips` methods **round** the computed SL/TP to the symbol's digits.

---

## `buyMarketWithSLTP(symbol, volume, sl, tp)` / `sellMarketWithSLTP(symbol, volume, sl, tp)`

Market order with absolute SL/TP prices.

**Signatures:** `uint64_t buyMarketWithSLTP(const std::string& symbol, double volume, double sl, double tp);` · `uint64_t sellMarketWithSLTP(const std::string& symbol, double volume, double sl, double tp);`

**Examples**

*1 — long with fixed SL/TP prices*
```cpp
double ask = sugar.getAsk("EURUSD");
uint64_t t = sugar.buyMarketWithSLTP("EURUSD", 0.01, ask - 0.0050, ask + 0.0050);
```

*2 — short, SL above / TP below*
```cpp
double bid = sugar.getBid("EURUSD");
uint64_t t = sugar.sellMarketWithSLTP("EURUSD", 0.01, bid + 0.0050, bid - 0.0050);
```

---

## `buyLimitWithSLTP(symbol, volume, price, sl, tp)` / `sellLimitWithSLTP(symbol, volume, price, sl, tp)`

Pending limit order at `price` with absolute SL/TP.

**Signatures:** `uint64_t buyLimitWithSLTP(const std::string& symbol, double volume, double price, double sl, double tp);` · `uint64_t sellLimitWithSLTP(const std::string& symbol, double volume, double price, double sl, double tp);`

**Examples**

*1 — buy-limit with protection*
```cpp
uint64_t t = sugar.buyLimitWithSLTP("EURUSD", 0.01, /*price*/1.0800, /*sl*/1.0770, /*tp*/1.0860);
```

*2 — sell-limit with protection*
```cpp
uint64_t t = sugar.sellLimitWithSLTP("EURUSD", 0.01, 1.0900, 1.0930, 1.0840);
```

---

## `buyMarketWithPips(symbol, volume, slPips, tpPips)` / `sellMarketWithPips(symbol, volume, slPips, tpPips)`

Market order with SL/TP expressed as **pip distances** from entry (rounded to digits for you).

**Signatures:** `uint64_t buyMarketWithPips(const std::string& symbol, double volume, double slPips, double tpPips);` · `uint64_t sellMarketWithPips(const std::string& symbol, double volume, double slPips, double tpPips);`

**Examples**

*1 — 20-pip stop, 40-pip target (2:1)*
```cpp
uint64_t t = sugar.buyMarketWithPips("EURUSD", 0.01, /*slPips*/20, /*tpPips*/40);
```

*2 — short, symmetric 30/30*
```cpp
uint64_t t = sugar.sellMarketWithPips("EURUSD", 0.01, 30, 30);
```

*3 — size by risk, then enter with pips*
```cpp
double lots = sugar.calculatePositionSize("EURUSD", 1.0 /*%*/, 20 /*pips*/);
uint64_t t  = sugar.buyMarketWithPips("EURUSD", lots, 20, 40);
```
