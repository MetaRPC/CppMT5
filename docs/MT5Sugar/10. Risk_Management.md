# MT5Sugar · Risk Management

> Size positions by risk, check affordability, and compute SL/TP prices — the helpers that turn an idea into a safely-sized order. Built on [MT5Service calculations](../MT5Service/4.%20Trading_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar).

> **Rounding:** `calculatePositionSize` / `getMaxLotSize` round the volume **down** to the symbol's `volumeStep`; `calculateSLTP` rounds the SL/TP prices to the symbol's digits.

---

## `calculatePositionSize(symbol, riskPercent, stopLossPips)`

Lot size so that a `stopLossPips` stop risks `riskPercent`% of the **balance**.

**Signature:** `double calculatePositionSize(const std::string& symbol, double riskPercent, double stopLossPips);`

**Examples**

*1 — risk 1% on a 20-pip stop*
```cpp
double lots = sugar.calculatePositionSize("EURUSD", 1.0, 20);
std::printf("sized: %.2f lots\n", lots);
```

*2 — size and enter in one flow*
```cpp
double lots = sugar.calculatePositionSize("EURUSD", 0.5 /*%*/, 30 /*pips*/);
if (lots > 0) sugar.buyMarketWithPips("EURUSD", lots, 30, 60);
```

---

## `getMaxLotSize(symbol)`

Largest lot the current **free margin** can open on this symbol.

**Signature:** `double getMaxLotSize(const std::string& symbol);`

**Examples**

*1 — cap an order at the affordable max*
```cpp
double want = 1.0;
double maxLots = sugar.getMaxLotSize("EURUSD");
double vol = std::min(want, maxLots);
if (vol > 0) sugar.buyMarket("EURUSD", vol);
```

---

## `canOpenPosition(symbol, volume, reason&)`

Whether a `volume`-lot order can be opened now; `reason` explains a `false`.

**Signature:** `bool canOpenPosition(const std::string& symbol, double volume, std::string& reason);`

**Examples**

*1 — pre-flight check*
```cpp
std::string why;
if (sugar.canOpenPosition("EURUSD", 0.50, why))
    sugar.buyMarket("EURUSD", 0.50);
else
    std::printf("cannot open: %s\n", why.c_str());
```

*2 — size, then confirm, then trade*
```cpp
double lots = sugar.calculatePositionSize("EURUSD", 1.0, 20);
std::string why;
if (sugar.canOpenPosition("EURUSD", lots, why))
    sugar.buyMarketWithPips("EURUSD", lots, 20, 40);
else
    std::printf("skip (%s)\n", why.c_str());
```

---

## `calculateRequiredMargin(symbol, volume)`

Margin needed to open `volume` lots (buy side), in account currency.

**Signature:** `double calculateRequiredMargin(const std::string& symbol, double volume);`

**Examples**

*1 — compare against free margin*
```cpp
double need = sugar.calculateRequiredMargin("EURUSD", 1.0);
std::printf("need %.2f / free %.2f\n", need, sugar.getFreeMargin());
```

---

## `calculateSLTP(symbol, direction, entryPrice, slPips, tpPips, slOut&, tpOut&)`

Compute absolute SL/TP prices for a direction (`"buy"` / `"sell"`) from pip distances.

**Signature:** `void calculateSLTP(const std::string& symbol, const std::string& direction, double entryPrice, double stopLossPips, double takeProfitPips, double& slOut, double& tpOut);`

**Examples**

*1 — derive prices, then place a limit*
```cpp
double sl, tp;
double entry = 1.0800;
sugar.calculateSLTP("EURUSD", "buy", entry, /*slPips*/20, /*tpPips*/40, sl, tp);
sugar.buyLimitWithSLTP("EURUSD", 0.01, entry, sl, tp);
```

*2 — short side*
```cpp
double sl, tp;
sugar.calculateSLTP("EURUSD", "sell", sugar.getBid("EURUSD"), 25, 50, sl, tp);
std::printf("sell SL %.5f TP %.5f\n", sl, tp);
```
