# MT5Sugar · Connection

> Connect, check liveness, and drop the channel — the one-liner front door to a session. Wraps [MT5Service connection](../MT5Service/MT5Service.Overview.md).

**🧩 Layer:** HIGH (MT5Sugar). **Header:** `#include <metarpc/mt5_sugar.hpp>`, namespace `metarpc`.

All methods throw `ApiError` / `TransportError` on failure (and `quickConnect()` throws `std::runtime_error` if an env var is missing).

---

## `connect(login, password, server, name="", timeoutSeconds=120)`

Connect by credentials and broker server name; blocks until the terminal is ready.

**Signature:** `void connect(int64_t login, const std::string& password, const std::string& server, const std::string& name = "", int timeoutSeconds = 120);`

**Examples**

*1 — minimal connect*
```cpp
MT5Sugar sugar("mt5.mrpc.pro", 443);
sugar.connect(5057947437, "password", "MetaQuotes-Demo");
```

*2 — custom terminal name + longer startup budget*
```cpp
sugar.connect(5057947437, "password", "MetaQuotes-Demo", "my-bot", /*timeoutSeconds*/180);
```

*3 — connect then sanity-check*
```cpp
sugar.connect(5057947437, "password", "MetaQuotes-Demo");
if (!sugar.ping()) { std::puts("connected but not responding"); return; }
```

---

## `quickConnect()`

Connect using the environment variables `MT5_LOGIN`, `MT5_PASSWORD`, `MT5_SERVER`.

**Signature:** `void quickConnect();`

**Examples**

*1 — the shortest start*
```cpp
MT5Sugar sugar;                 // defaults to mt5.mrpc.pro:443
sugar.quickConnect();           // reads MT5_LOGIN / MT5_PASSWORD / MT5_SERVER
```

*2 — handle a missing variable*
```cpp
try {
    sugar.quickConnect();
} catch (const std::runtime_error& e) {
    std::printf("env not set: %s\n", e.what());
}
```

---

## `isConnected()`

Whether a successful connect has happened on this client.

**Signature:** `bool isConnected() const;`

**Examples**

*1 — branch on state*
```cpp
if (!sugar.isConnected()) sugar.quickConnect();
```

---

## `ping()`

Liveness probe: fetches the account summary and returns `true` if it succeeds.

**Signature:** `bool ping();`

**Examples**

*1 — health check*
```cpp
std::printf("alive: %s\n", sugar.ping() ? "yes" : "no");
```

*2 — reconnect loop*
```cpp
if (!sugar.ping()) {
    std::puts("stale — reconnecting");
    sugar.connect(5057947437, "password", "MetaQuotes-Demo");
}
```

---

## `disconnect()`

Drop the gRPC channel. The terminal keeps running on the server (use the service/account layer's `disconnect()` to actually stop it).

**Signature:** `void disconnect();`

**Examples**

*1 — clean shutdown*
```cpp
sugar.disconnect();
```

---

## `service()` / `account()`

Reach the lower layers for anything not wrapped here.

**Signatures:** `MT5Service& service();` · `MT5Account& account();`

**Examples**

*1 — drop to the mid-level facade*
```cpp
AccountInfo info = sugar.service().accountSummary();
```

*2 — drop to the raw layer*
```cpp
namespace pb = mt5_term_api;
pb::AccountSummaryData raw = sugar.account().accountSummary();
```
