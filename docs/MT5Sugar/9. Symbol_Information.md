# MT5Sugar · Symbol Information

> Quick symbol look-ups a strategy needs before trading — full spec, availability, digits, and the minimum stop distance. Wraps [MT5Service symbol reads](../MT5Service/2.%20Symbol_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar).

---

## `getSymbolInfo(symbol)`

Full parameters for a symbol (returns the friendly `SymbolInfo` struct).

**Signature:** `SymbolInfo getSymbolInfo(const std::string& symbol);`

**Examples**

*1 — read the essentials*
```cpp
SymbolInfo s = sugar.getSymbolInfo("EURUSD");
std::printf("%s: digits=%d point=%.5f volMin=%.2f step=%.2f\n",
            s.name.c_str(), s.digits, s.point, s.volumeMin, s.volumeStep);
```

*2 — normalize a desired volume to the step*
```cpp
SymbolInfo s = sugar.getSymbolInfo("EURUSD");
double want = 0.037;
double norm = std::round(want / s.volumeStep) * s.volumeStep;
norm = std::max(s.volumeMin, std::min(s.volumeMax, norm));
```

## `getAllSymbols()`

Every symbol name on the terminal.

**Signature:** `std::vector<std::string> getAllSymbols();`

**Examples**

*1 — count & sample*
```cpp
auto all = sugar.getAllSymbols();
std::printf("%zu symbols; first: %s\n", all.size(), all.empty() ? "-" : all.front().c_str());
```

*2 — filter to a prefix*
```cpp
for (const auto& s : sugar.getAllSymbols())
    if (s.rfind("EUR", 0) == 0) std::printf("%s\n", s.c_str());
```

## `isSymbolAvailable(symbol)`

True if the symbol exists and can be selected/traded.

**Signature:** `bool isSymbolAvailable(const std::string& symbol);`

**Examples**

*1 — guard before trading*
```cpp
if (!sugar.isSymbolAvailable("EURUSD")) { std::puts("symbol unavailable"); return; }
sugar.buyMarket("EURUSD", 0.01);
```

---

## `getMinStopLevel(symbol)`

Minimum SL/TP distance from price, in **points**.

**Signature:** `int64_t getMinStopLevel(const std::string& symbol);`

**Examples**

*1 — keep a stop legal*
```cpp
int64_t minPts = sugar.getMinStopLevel("EURUSD");
SymbolInfo s = sugar.getSymbolInfo("EURUSD");
double minDist = minPts * s.point;              // convert points → price
double sl = sugar.getAsk("EURUSD") - std::max(0.0030, minDist);
```

---

## `getSymbolDigits(symbol)`

Number of price decimal places.

**Signature:** `int getSymbolDigits(const std::string& symbol);`

**Examples**

*1 — format a price correctly*
```cpp
int d = sugar.getSymbolDigits("EURUSD");          // 5
std::printf("%.*f\n", d, sugar.getBid("EURUSD"));
```
