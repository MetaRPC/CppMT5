# MT5Sugar · Position Management

> Close and modify positions — one, by symbol, or all at once. Wraps [MT5Service::orderClose / orderModify](../MT5Service/4.%20Trading_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar). `bool` methods return `true` on an accepted retcode; bulk methods return the count affected.

---

## `closePosition(ticket)`

Close a whole position by ticket.

**Signature:** `bool closePosition(int64_t ticket);`

**Examples**

*1 — close one*
```cpp
if (sugar.closePosition(123456)) std::puts("closed");
```

*2 — close what you just opened*
```cpp
uint64_t t = sugar.buyMarket("EURUSD", 0.01);
if (t) sugar.closePosition((int64_t)t);
```

---

## `closePositionPartial(ticket, volume)`

Close part of a position (the rest stays open).

**Signature:** `bool closePositionPartial(int64_t ticket, double volume);`

**Examples**

*1 — scale out half*
```cpp
bool found = false;
Position p = sugar.getPositionByTicket(123456, found);
if (found) sugar.closePositionPartial(p.ticket, p.volume / 2.0);
```

---

## `closeAllPositions()`

Close every open position; returns how many were closed.

**Signature:** `int closeAllPositions();`

**Examples**

*1 — flatten everything*
```cpp
int n = sugar.closeAllPositions();
std::printf("closed %d position(s)\n", n);
```

*2 — emergency stop on drawdown*
```cpp
if (sugar.getProfit() < -100) sugar.closeAllPositions();
```

---

## `closeAllBySymbol(symbol)`

Close all positions on one symbol; returns the count closed.

**Signature:** `int closeAllBySymbol(const std::string& symbol);`

**Examples**

*1 — exit a single market*
```cpp
int n = sugar.closeAllBySymbol("EURUSD");
std::printf("closed %d EURUSD position(s)\n", n);
```

---

## `modifyPositionSL(ticket, sl)` / `modifyPositionTP(ticket, tp)`

Set only the stop loss / only the take profit.

**Signatures:** `bool modifyPositionSL(int64_t ticket, double sl);` · `bool modifyPositionTP(int64_t ticket, double tp);`

**Examples**

*1 — move stop to break-even*
```cpp
bool found = false;
Position p = sugar.getPositionByTicket(123456, found);
if (found) sugar.modifyPositionSL(p.ticket, p.priceOpen);
```

*2 — tighten the target*
```cpp
sugar.modifyPositionTP(123456, 1.0880);
```

---

## `modifyPositionSLTP(ticket, sl, tp)`

Set both SL and TP in one call.

**Signature:** `bool modifyPositionSLTP(int64_t ticket, double sl, double tp);`

**Examples**

*1 — set both*
```cpp
sugar.modifyPositionSLTP(123456, /*sl*/1.0800, /*tp*/1.0900);
```

*2 — trail behind price*
```cpp
bool found = false;
Position p = sugar.getPositionByTicket(123456, found);
if (found && p.isBuy()) {
    double newSl = sugar.getBid(p.symbol) - 0.0030;     // 30-pip trail
    if (newSl > p.stopLoss) sugar.modifyPositionSLTP(p.ticket, newSl, p.takeProfit);
}
```
