# MT5Sugar · Simple Trading

> Market and pending orders in one line each. Every method returns the **resulting ticket** (`uint64_t`), or `0` on a rejected order. Wraps [MT5Service::orderSend](../MT5Service/4.%20Trading_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar). Throws `ApiError` / `TransportError` on transport/validation failure; a rejected trade returns `0`.

> **No rounding.** Volumes/prices are sent exactly as given — normalize against the symbol's `volumeStep` / `digits` yourself, or use the [Risk Management](./10.%20Risk_Management.md) helpers.

---

## `buyMarket(symbol, volume)` / `sellMarket(symbol, volume)`

Market BUY / SELL at the current price, no SL/TP.

**Signatures:** `uint64_t buyMarket(const std::string& symbol, double volume);` · `uint64_t sellMarket(const std::string& symbol, double volume);`

**Examples**

*1 — go long*
```cpp
uint64_t t = sugar.buyMarket("EURUSD", 0.01);
if (t) std::printf("opened #%llu\n", (unsigned long long)t);
else   std::puts("order rejected");
```

*2 — go short and remember the ticket*
```cpp
uint64_t ticket = sugar.sellMarket("GBPUSD", 0.02);
// ... later ...
if (ticket) sugar.closePosition((int64_t)ticket);
```

*3 — flip a position*
```cpp
uint64_t shortT = sugar.sellMarket("EURUSD", 0.01);
if (shortT) { sugar.closePosition((int64_t)shortT); sugar.buyMarket("EURUSD", 0.01); }
```

---

## `buyLimit(symbol, volume, price)` / `sellLimit(symbol, volume, price)`

Pending BUY LIMIT (below market) / SELL LIMIT (above market).

**Signatures:** `uint64_t buyLimit(const std::string& symbol, double volume, double price);` · `uint64_t sellLimit(const std::string& symbol, double volume, double price);`

**Examples**

*1 — buy the dip*
```cpp
double entry = sugar.getBid("EURUSD") - 0.0020;
uint64_t t = sugar.buyLimit("EURUSD", 0.01, entry);
```

*2 — sell into strength*
```cpp
uint64_t t = sugar.sellLimit("EURUSD", 0.01, sugar.getAsk("EURUSD") + 0.0020);
```

---

## `buyStop(symbol, volume, price)` / `sellStop(symbol, volume, price)`

Pending BUY STOP (above market) / SELL STOP (below market) — breakout entries.

**Signatures:** `uint64_t buyStop(const std::string& symbol, double volume, double price);` · `uint64_t sellStop(const std::string& symbol, double volume, double price);`

**Examples**

*1 — breakout long*
```cpp
double trigger = sugar.getAsk("EURUSD") + 0.0030;
uint64_t t = sugar.buyStop("EURUSD", 0.01, trigger);
```

*2 — breakdown short*
```cpp
uint64_t t = sugar.sellStop("EURUSD", 0.01, sugar.getBid("EURUSD") - 0.0030);
```
