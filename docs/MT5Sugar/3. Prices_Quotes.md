# MT5Sugar · Prices / Quotes

> Current prices in one line, plus a compact snapshot and a price-wait helper. Wraps [MT5Service symbol reads](../MT5Service/2.%20Symbol_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar). Throws `ApiError` / `TransportError` on failure.

```cpp
struct PriceInfo { std::string symbol; double bid, ask, spread; int64_t time; };  // time = UTC seconds
```

---

## `getBid(symbol)` / `getAsk(symbol)`

Current best bid / ask.

**Signatures:** `double getBid(const std::string& symbol);` · `double getAsk(const std::string& symbol);`

**Examples**

*1 — read both*
```cpp
std::printf("EURUSD %.5f / %.5f\n", sugar.getBid("EURUSD"), sugar.getAsk("EURUSD"));
```

*2 — mid price*
```cpp
double mid = (sugar.getBid("EURUSD") + sugar.getAsk("EURUSD")) / 2.0;
```

---

## `getSpread(symbol)`

`ask - bid` in price units.

**Signature:** `double getSpread(const std::string& symbol);`

**Examples**

*1 — only trade on a tight spread*
```cpp
if (sugar.getSpread("EURUSD") <= 0.00015)
    sugar.buyMarket("EURUSD", 0.01);
```

---

## `getPriceInfo(symbol)`

bid / ask / spread / time in a single call.

**Signature:** `PriceInfo getPriceInfo(const std::string& symbol);`

**Examples**

*1 — one call for everything*
```cpp
PriceInfo p = sugar.getPriceInfo("EURUSD");
std::printf("%.5f / %.5f (spread %.5f)\n", p.bid, p.ask, p.spread);
```

*2 — timestamped log line*
```cpp
PriceInfo p = sugar.getPriceInfo("XAUUSD");
std::printf("[UTC %lld] XAUUSD %.2f\n", (long long)p.time, p.bid);
```

---

## `waitForPrice(symbol, targetBid, timeoutMs=10000)`

Poll until the bid reaches `targetBid` (or any tick when `targetBid == 0`), up to `timeoutMs`. Returns the last price seen; the result's `symbol` is empty on timeout.

**Signature:** `PriceInfo waitForPrice(const std::string& symbol, double targetBid, int timeoutMs = 10000);`

**Examples**

*1 — wait for a breakout level*
```cpp
PriceInfo hit = sugar.waitForPrice("EURUSD", 1.0900, 30000);
if (!hit.symbol.empty()) {
    std::printf("level reached at %.5f\n", hit.bid);
    sugar.buyMarket("EURUSD", 0.01);
} else {
    std::puts("timed out waiting for level");
}
```

*2 — wait for the next tick*
```cpp
PriceInfo t = sugar.waitForPrice("EURUSD", 0 /*any tick*/, 5000);
```
