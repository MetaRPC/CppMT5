# MT5Sugar · History / Statistics

> Closed-trade history over convenient windows (today, yesterday, this week/month, custom), realized-profit totals, and a one-call daily summary. Day boundaries are **UTC**. Wraps [MT5Service::positionsHistory](../MT5Service/3.%20Position_Orders_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar). History methods return `std::vector<PositionHistory>`.

```cpp
struct DailyStats { int totalDeals, winningDeals, losingDeals;
                    double winRate, totalProfit, bestDeal, worstDeal; };
```

---

## `getDealsToday()` / `getDealsYesterday()` / `getDealsThisWeek()` / `getDealsThisMonth()`

Closed positions over the named window.

**Signatures:** `std::vector<PositionHistory> getDealsToday();` (and `...Yesterday()` / `...ThisWeek()` / `...ThisMonth()`)

**Examples**

*1 — count today's trades*
```cpp
auto today = sugar.getDealsToday();
std::printf("%zu closed trades today\n", today.size());
```

*2 — list this week with P/L*
```cpp
for (const PositionHistory& h : sugar.getDealsThisWeek())
    std::printf("#%lld %s  P/L %.2f\n", (long long)h.ticket, h.symbol.c_str(), h.profit);
```

---

## `getDealsDateRange(fromUnix, toUnix)`

Closed positions in a custom UTC window.

**Signature:** `std::vector<PositionHistory> getDealsDateRange(int64_t fromUnix, int64_t toUnix);`

**Examples**

*1 — last 90 days*
```cpp
#include <ctime>
int64_t now = (int64_t)std::time(nullptr);
auto quarter = sugar.getDealsDateRange(now - 90LL*24*3600, now);
std::printf("%zu trades in the last 90 days\n", quarter.size());
```

---

## `getProfitToday()` / `getProfitThisWeek()` / `getProfitThisMonth()`

Net realized profit over the window.

**Signatures:** `double getProfitToday();` · `double getProfitThisWeek();` · `double getProfitThisMonth();`

**Examples**

*1 — daily P&L line*
```cpp
std::printf("Today %.2f | Week %.2f | Month %.2f\n",
            sugar.getProfitToday(), sugar.getProfitThisWeek(), sugar.getProfitThisMonth());
```

*2 — stop trading after a daily loss limit*
```cpp
if (sugar.getProfitToday() < -200) { std::puts("daily loss limit hit"); sugar.closeAllPositions(); }
```

---

## `getDailyStats()`

Today's win/loss summary in one struct.

**Signature:** `DailyStats getDailyStats();`

**Examples**

*1 — print the scorecard*
```cpp
DailyStats d = sugar.getDailyStats();
std::printf("Deals %d | Wins %d | Losses %d | Win rate %.0f%% | Net %.2f\n",
            d.totalDeals, d.winningDeals, d.losingDeals, d.winRate, d.totalProfit);
std::printf("Best %.2f | Worst %.2f\n", d.bestDeal, d.worstDeal);
```

*2 — gate new entries on today's win rate*
```cpp
DailyStats d = sugar.getDailyStats();
if (d.totalDeals >= 5 && d.winRate < 30) std::puts("rough day — pausing entries");
```
