# MT5Sugar · Account Information

> The whole account snapshot in one call. Wraps [MT5Service::accountSummary](../MT5Service/1.%20Account_Methods.md) and returns the friendly `AccountInfo` struct.

**🧩 Layer:** HIGH (MT5Sugar).

```cpp
struct AccountInfo {
    int64_t login; std::string currency;
    double balance, equity, credit; int64_t leverage;
    std::string name, company; TradeMode tradeMode;      // Demo / Contest / Real
    int64_t serverTime, serverTimeUtc, utcShiftMinutes;  // unix seconds
    std::string server;
};
```

> For a **single** figure, the [Balance / Margin](./2.%20Balance_Margin.md) one-liners (`getBalance()`, `getEquity()`, …) are shorter. Use `getAccountInfo()` when you need several fields at once.

---

## `getAccountInfo()`

Full account snapshot.

**Signature:** `AccountInfo getAccountInfo();`

**Examples**

*1 — a status line*
```cpp
AccountInfo a = sugar.getAccountInfo();
std::printf("Acc %lld | %s | Bal %.2f | Eq %.2f | Lev 1:%lld | %s\n",
            (long long)a.login, a.currency.c_str(), a.balance, a.equity,
            (long long)a.leverage, a.company.c_str());
```

*2 — refuse to run on a real account*
```cpp
AccountInfo a = sugar.getAccountInfo();
if (a.tradeMode == TradeMode::Real)
    throw std::runtime_error("refusing to run a test strategy on a REAL account");
```

*3 — show server time (UTC)*
```cpp
#include <ctime>
AccountInfo a = sugar.getAccountInfo();
std::time_t utc = (std::time_t)a.serverTimeUtc;
char buf[32]; std::strftime(buf, sizeof buf, "%F %T", std::gmtime(&utc));
std::printf("server time (UTC): %s\n", buf);
```
