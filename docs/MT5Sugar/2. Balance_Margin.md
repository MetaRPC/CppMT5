# MT5Sugar · Balance / Margin

> Six one-liners for the account's money figures. Each returns a `double` and wraps [MT5Service account reads](../MT5Service/1.%20Account_Methods.md).

**🧩 Layer:** HIGH (MT5Sugar). Throws `ApiError` / `TransportError` on failure.

---

## `getBalance()`

Account balance — settled money, excludes floating P/L.

**Signature:** `double getBalance();`

**Examples**

*1 — read it*
```cpp
std::printf("Balance: %.2f\n", sugar.getBalance());
```

*2 — guard before trading*
```cpp
if (sugar.getBalance() < 100) { std::puts("balance too low"); return; }
```

---

## `getEquity()`

Equity = balance + floating P/L of open positions.

**Signature:** `double getEquity();`

**Examples**

*1 — read it*
```cpp
std::printf("Equity: %.2f\n", sugar.getEquity());
```

*2 — drawdown vs balance*
```cpp
double dd = sugar.getBalance() - sugar.getEquity();
if (dd > 0) std::printf("floating loss: %.2f\n", dd);
```

---

## `getMargin()` / `getFreeMargin()`

Used margin and free margin (account currency).

**Signatures:** `double getMargin();` · `double getFreeMargin();`

**Examples**

*1 — how much room is left*
```cpp
std::printf("Used %.2f | Free %.2f\n", sugar.getMargin(), sugar.getFreeMargin());
```

*2 — can I afford more?*
```cpp
if (sugar.getFreeMargin() < 50) std::puts("not enough free margin");
```

---

## `getMarginLevel()`

Margin level in percent (`equity / margin × 100`); `0` when nothing is open.

**Signature:** `double getMarginLevel();`

**Examples**

*1 — risk gauge*
```cpp
double lvl = sugar.getMarginLevel();
if (lvl != 0 && lvl < 150) std::puts("⚠️ margin level low");
```

*2 — auto-protect*
```cpp
if (sugar.getMarginLevel() != 0 && sugar.getMarginLevel() < 120)
    sugar.closeAllPositions();
```

---

## `getProfit()`

Current total floating profit of all open positions.

**Signature:** `double getProfit();`

**Examples**

*1 — read it*
```cpp
std::printf("Floating P/L: %.2f\n", sugar.getProfit());
```

*2 — take profit on the whole book*
```cpp
if (sugar.getProfit() > 50) {
    std::puts("target hit — closing all");
    sugar.closeAllPositions();
}
```
