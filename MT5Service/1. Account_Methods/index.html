    MT5Service — Account Methods (Mid-Level)¶

    4 methods for account properties without protobuf ceremony. They wrap the MT5Account Account Information RPCs and return clean C++ values.

    🧩 API Layer: MID-LEVEL — wrappers over MT5Account returning native C++ types.

    Implementation: src/mt5_service.cpp (header include/metarpc/mt5_service.hpp).

    🎯 Why these exist¶

    // Low-level (MT5Account): build request, unpack Data
namespace pb = mt5_term_api;
pb::AccountInfoDoubleRequest r; r.set_property_id(pb::ACCOUNT_BALANCE);
double balance = account.accountInfoDouble(r).requested_value();

// Mid-level (MT5Service): one call, plain value
double balance = service.accountInfoDouble(pb::ACCOUNT_BALANCE);
    • ✅ Returns double / int64_t / std::string / AccountInfo directly
    • ✅ Builds the request for you, unpacks the Data
    • ✅ accountSummary() fills serverTimeUtc already converted

    📋 The 4 methods¶

    Method Returns Low-level equivalent
    accountSummary() AccountInfo MT5Account::accountSummary()
    accountInfoDouble(propertyId) double accountInfoDouble(req) → requested_value()
    accountInfoInteger(propertyId) int64_t accountInfoInteger(req) → requested_value()
    accountInfoString(propertyId) std::string accountInfoString(req) → requested_value()

    propertyId is a plain int — pass the protobuf enum value (e.g. pb::ACCOUNT_BALANCE), which converts to int implicitly.

    📦 AccountInfo (DTO)¶

    struct AccountInfo {
    int64_t      login;
    std::string  currency;
    double       balance, equity, credit;
    int64_t      leverage;
    std::string  name, company;
    TradeMode    tradeMode;          // Demo / Contest / Real
    int64_t      serverTime;         // unix seconds, broker clock (raw)
    int64_t      serverTimeUtc;      // same instant in UTC
    int64_t      utcShiftMinutes;    // server clock minus UTC
    std::string  server;             // broker server name used to connect
};

    📖 Methods¶

    1) accountSummary()¶

    AccountInfo accountSummary();

    All account info in one call — use this for 2+ properties.

    2) accountInfoDouble(int propertyId)¶

    double accountInfoDouble(int propertyId);

    Common ids (AccountInfoDoublePropertyType): ACCOUNT_BALANCE(0), ACCOUNT_CREDIT(1), ACCOUNT_PROFIT(2), ACCOUNT_EQUITY(3), ACCOUNT_MARGIN(4), ACCOUNT_MARGIN_FREE(5), ACCOUNT_MARGIN_LEVEL(6) … (14 total).

    3) accountInfoInteger(int propertyId)¶

    int64_t accountInfoInteger(int propertyId);

    Common ids (AccountInfoIntegerPropertyType): ACCOUNT_LOGIN(0), ACCOUNT_TRADE_MODE(1), ACCOUNT_LEVERAGE(2), ACCOUNT_TRADE_ALLOWED(5), ACCOUNT_MARGIN_MODE(7) … (11 total).

    4) accountInfoString(int propertyId)¶

    std::string accountInfoString(int propertyId);

    Ids (AccountInfoStringPropertyType): ACCOUNT_NAME(0), ACCOUNT_SERVER(1), ACCOUNT_CURRENCY(2), ACCOUNT_COMPANY(3).

    💡 Examples¶

    Balance + equity (one call)¶

    AccountInfo s = service.accountSummary();
std::printf("Balance %.2f %s | Equity %.2f | Lev 1:%lld | Broker %s\n",
            s.balance, s.currency.c_str(), s.equity,
            (long long)s.leverage, s.company.c_str());

    Single property¶

    namespace pb = mt5_term_api;
double freeMargin = service.accountInfoDouble(pb::ACCOUNT_MARGIN_FREE);
if (freeMargin < 100) std::puts("⚠️ low free margin");

    Demo vs real guard¶

    if (service.accountInfoInteger(pb::ACCOUNT_TRADE_MODE) == 2 /* REAL */)
    throw std::runtime_error("refusing to run on a REAL account");

    Balance monitor¶

    #include <thread>
#include <chrono>
for (;;) {
    std::printf("Balance: %.2f\n", service.accountInfoDouble(pb::ACCOUNT_BALANCE));
    std::this_thread::sleep_for(std::chrono::seconds(5));
}

    🔧 When to use which¶

    1. One property → accountInfoDouble/Integer/String.
    2. Two or more → accountSummary() (already has everything).
    3. Dashboard / report → accountSummary().
